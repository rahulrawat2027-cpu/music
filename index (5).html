Setup and keys

Everything runs in your browser. Tokens stay in this tab and in localStorage; nothing is sent to a server of mine. Deploy by dropping this file at the root of a repo and importing it into Vercel as a static project.

Redirect URI to register with Spotify, and the authorised origin for Google:

The Apple token has to be signed with your .p8 private key, which can't be done safely in a browser — generate it offline and paste it here. It lasts up to six months.

YouTube's API charges 100 quota units per search and 50 per track added, against a default daily budget of 10,000. A 60-track playlist costs roughly 9,000, so expect to sync about one playlist a day until you request more.
